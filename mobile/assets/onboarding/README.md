Illustrations extraites des maquettes fournies dans `FitBuddy_Onboarding_01-16`.
Seules les illustrations sont utilisées comme images : tous les textes, cartes,
champs, indicateurs et boutons de l'onboarding sont des composants interactifs.

Reproduction des découpes : `node scripts/prepare-onboarding-assets.cjs` depuis
`mobile/` (utilise le décodeur PNG déjà présent dans les dépendances Expo).
Les assets 3D validés de `10_Assets_3D` restent prioritaires lorsqu'ils existent.
